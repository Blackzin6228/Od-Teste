# Cores dos elementos em tudo (2026-11-08)
**Decisão:** cada elemento tem uma cor fixa, e ela aparece em **tudo** que é daquele elemento: partículas, brilho, Marca, vinheta
e efeitos de tela, interface, nomes de item, criaturas, rituais, aparelhos e resource pack. Cor é informação: o jogador
reconhece o elemento pela cor, antes de ler qualquer coisa.

| Elemento | Cor principal | Tons (escuro → claro) | Brilho |
|---|---|---|---|
| Sangue | vermelho | `#3A0306` `#7A0A10` `#B3131B` `#E0313A` | vermelho vivo pulsando |
| Conhecimento | dourado / amarelo | `#3D2E05` `#8A6A12` `#D4A82A` `#F5DC7A` | dourado com branco no centro |
| Morte | cinza / preto | `#0B0B0D` `#2A2A2E` `#5E5E66` `#A8A8B0` | cinza frio, quase sem brilho, poeira |
| Energia | roxo | `#1E0838` `#4B1A8C` `#8A3DDB` `#C79BFF` | roxo neon com faíscas de ciano e rosa |
| Medo (fundo) | preto absoluto | `#000000` | nenhum: é a ausência |

**Regras:** fundo da interface preto, com **um único acento** (a cor do elemento em foco). Elementos misturados usam as duas
cores, nunca uma terceira inventada. Valores acima são ponto de partida: a mesa Modelador pode ajustar o tom com prévia
aprovada, sem trocar a cor.
**Por quê:** pedido do Nikolas, para o mod e o pack terem a identidade visual do gênero com a máxima qualidade.
