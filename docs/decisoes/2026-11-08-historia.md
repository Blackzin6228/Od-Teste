# Como a história é contada (2026-11-08)
**Decisão:** os protagonistas são os próprios jogadores (os textos usam o nome de quem está jogando, nunca nome fixo). A história chega por pistas no mundo, eventos ao vivo disparados pelo admin e enigmas de verdade. Enigmas avançam sozinhos; os grandes eventos de entidade o admin solta. Pouco grind: avança descobrindo e sobrevivendo, não juntando recurso.
