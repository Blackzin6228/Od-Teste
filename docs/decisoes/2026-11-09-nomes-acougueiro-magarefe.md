# Nomes: Diário do Açougueiro e Magarefe (2026-11-09)
**Decisão:** o item se chama **"Diário do Açougueiro"** (não "Livro do Carniceiro"). A criatura se chama **"Magarefe"**.
**Por quê:** "açougueiro" é palavra que todo jogador conhece; "Magarefe" (quem abate gado) é raro e soa estranho, bom para criatura.
**Substitui:** "Livro do Carniceiro".
