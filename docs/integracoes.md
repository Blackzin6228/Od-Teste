# Papel de cada mod do pack (PROPOSTA — esperando o Nikolas)

Ideia geral: o paranormal vaza para o mundo e **cada tradição tenta lidar com ele do seu jeito**.
Cada mod do pack vira uma dessas tradições. O jogador escolhe por onde entra, mas a progressão boa cruza duas ou mais.

| Mod | Tradição na lore (proposta) | Como integra no jogo |
|---|---|---|
| **Occultism** | Os ritualistas: desenham círculos de giz para chamar e prender | Rituais nossos usando o giz e os pentáculos do Occultism; símbolos novos nossos |
| **Iron's Spells** | Os conjuradores: falam e gesticulam o paranormal | Uma escola de magia nova, com magias próprias e livro próprio |
| **Malum** | Os que colhem almas | Almas de criaturas nossas viram espíritos do Malum; altar como etapa de progressão |
| **Vampirism** | Os que pagam com sangue | Marcas no corpo que custam sangue; caçadores com ferramentas contra criaturas nossas |
| **Botânia** | A natureza que resiste (ou apodrece) | Flores corrompidas pelo paranormal; mana como "remédio" para áreas afetadas |
| **Mekanism + Create** | Os céticos: medem, contêm e processam | Máquinas e contraptions para detectar, conter e transformar material paranormal (sem precisar de magia) |

Regra técnica: cada linha acima vira um pacote `compat/<mod>/` que só liga se o mod estiver no pack.
